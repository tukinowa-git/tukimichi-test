# site-assets

Webサイトのフロントエンド用アセット（CSS / JavaScript）。
ノーコードツールの埋め込みコードから外部読み込みしています。

| ファイル | 中身 |
|---|---|
| `book.v1.css` | UIのスタイル定義 |
| `book.v1.js` | 表示制御スクリプト（GSAP依存） |
| `.nojekyll` | GitHub Pages の Jekyll 処理を止める空ファイル。消さないこと |

## 更新のしかた

1. ファイルを編集する
2. **ファイル名の版を上げる**（`book.v1.css` → `book.v2.css`）。古いファイルは消さずに残す
3. Releases から新しいタグを作る（`v1.0.0` → `v2.0.0`）
4. 読み込み側の `v1` を `v2`、`@v1.0.0` を `@v2.0.0` に書き換える

ファイル名で版を管理しているため、キャッシュのパージ操作は不要です。
問題があれば読み込み側の版を戻すだけで復旧できます。

## 注意

- このリポジトリは Public です。**APIキーやパスワードは置かないこと。**
- `.nojekyll` を消すと GitHub Pages の挙動が変わります。
